# Publishing QA Checklist

Use for EPUB, PDF, POD, manuscript, and release files.

- [ ] Confirm source artifact names.
- [ ] Confirm final file versions.
- [ ] Run EPUB validation if EPUB is present.
- [ ] Run PDF metadata/page-size checks if PDF is present.
- [ ] Check internal links.
- [ ] Check cover/image resolution.
- [ ] Confirm paid files are not placed in public web assets.
- [ ] Store paid files only in private storage or protected delivery.
- [ ] Record results in reports.
