## Fixes applied in v13.1 (on top of uploaded v13)

1. **Title-page clipping (formatting bug).** `body.title-page-body h1.main-title`
   was fixed at 4.5rem with higher specificity than the responsive override, so
   "CONTEMPLATION" clipped on any viewport ≲ 850 px (phones, small tablets).
   Reduced base to 4rem and added equal-specificity media overrides *after* the
   base rule (768 px → 2.75rem, 600 px → 2rem, 360 px → 1.6rem), plus matching
   small-width tiers for the generic `h1.main-title` (half-title page).
   Verified clean at 320/400/500/600/800/1000 px.
2. **Dead link — AOL/Jen Atkin (Ch III endnote + bibliography).** The
   aol.com URL (live on 2026-06-10 per BUILD-MANIFEST) now 404s. Replaced with
   the live, identical Yahoo syndication page
   (`yahoo.com/entertainment/jen-atkin-gets-candid-her-171015077.html`, HTTP 200,
   content verified) and updated source label/date to match the live page
   (*Yahoo Entertainment*, updated September 11, 2018).
3. **Dead link — Allure/Ursula Stephen (Ch I endnote + bibliography).** URL 404s,
   no Wayback snapshot, not in search indexes. Per repo precedent ("no
   replacement URL invented"), removed the URL; print-style citation retained.
4. **Dead link — AP News (bibliography).** Deep slug 404s and the canonical AP
   URL is not verifiable (AP blocks crawlers); article itself verified real
   (Mae Anderson, AP, 2024-03-06, widely syndicated). Removed the URL;
   print-style citation retained.
5. **`dcterms:modified`** bumped to 2026-07-02T18:20:00Z.

**Defects found in the previously shipped `Curls-and-Contemplation-v13-RECTO-POD-Interior-FINAL.pdf` (GitHub upload, commit f2a0f20) that this build corrects:**

1. **Acknowledgments closing page missing.** The signature ("With deep
   gratitude…"), the P.S. box ("…Trust the dance."), and the closing quote
   ("In gratitude, we find connection…") rendered as a light-ink page that the
   build pipeline's blank-detector dropped. Restored (now p429).
2. **Printed TOC truncated.** The TOC's sparse third page (Manifesting Journal
   → Bibliography, 8 entries) was dropped the same way. Restored (TOC now
   pp5–7, all 36 entries printed with correct folios).
3. **Copyright disclaimer orphan.** The bottom-aligned copyright block overran
   the page by ~3 lines ("no guarantees… contained herein."), orphaning them
   onto a page that was dropped. Bottom padding reclaimed in print so the full
   notice fits one page.
4. **Stale TOC folios.** The repo TOC carried v11-era page numbers; both TOC
   folios and `release/page-map.json` now match the actual imposed layout.

The pipeline defect (1–2) also existed in the v8/v11 POD PDFs.
