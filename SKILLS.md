# SKILLS.md — Harness Skill Map

## Purpose

Use this file to select the correct workflow before execution.

## Skill 1 — Repo inspection

Use for every task.

Checklist:

- Read instruction files.
- Map affected files.
- Check package scripts.
- Check existing docs and reports.
- Identify risky areas.

## Skill 2 — Build/code execution

Use when editing code.

Checklist:

- Preserve existing architecture.
- Keep changes minimal.
- Add/update tests when behavior changes.
- Run lint, typecheck, test, and build where available.

## Skill 3 — Web/app QA

Use for websites, landing pages, dashboards, checkout, auth, admin, and customer pages.

Checklist:

- Verify desktop and mobile layout.
- Verify accessibility basics.
- Verify no broken navigation paths.
- Capture screenshots.
- Keep critical flows readable and low-motion.

## Skill 4 — Publishing QA

Use for EPUB, PDF, book, manuscript, release, or print tasks.

Checklist:

- Keep paid deliverables private.
- Validate EPUB/PDF with available tools.
- Check metadata, links, page size, image resolution, and file names.
- Never place paid files in public web assets.

## Skill 5 — Security/provider QA

Use for payment, auth, storage, webhooks, email, analytics, admin, or deployment tasks.

Checklist:

- Sandbox/test first.
- No real secrets committed.
- Fail closed when provider configuration is missing.
- Webhooks verify signatures.
- Downloads require entitlement.
- Admin requires authorization.

## Skill 6 — Brand/copy QA

Use for marketing copy, SEO, schema, product pages, landing pages, and email copy.

Checklist:

- Use the brand system.
- No fake urgency.
- No fake reviews.
- No invented testimonials.
- No fake awards or bestseller claims.
- Tag unverified claims for review.

## Skill 7 — Final handoff

Use at the end of every task.

Checklist:

- Files changed.
- Commands run.
- Results.
- Screenshots/reports.
- Security notes.
- Blockers.
- Next action.
